# Security Policy

Full details of the Automattic Security Policy can be found at [automattic.com/security](https://automattic.com/security/).

## Supported Versions

Security fixes are applied to the latest version on the default branch (`trunk`).

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues or pull requests.

For responsible disclosure of security issues and to be eligible for our bug bounty program, submit your report through the [Automattic HackerOne portal](https://hackerone.com/automattic).

Please note that WordPress core is a separate project from Automattic. Report vulnerabilities in WordPress core through the [WordPress Foundation HackerOne page](https://hackerone.com/wordpress).

## Guidelines

- Follow [HackerOne's disclosure guidelines](https://www.hackerone.com/disclosure-guidelines).
- Test against a local environment whenever possible.
- Allow reasonable time for us to investigate and address the issue before public disclosure.
